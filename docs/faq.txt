## What is MDPro4?

**MDPro4 is a community Yu-Gi-Oh! simulator built in Unity, combining YGOPro-style dueling with Master Duel assets and presentation.**

Its modes, supported cards and features follow MDPro4's own releases. It is a separate community project, so an update or feature in the official Master Duel game does not automatically appear here.

New here? Start with the download instructions for your platform, then check the card and online-play guides below.

## What is the latest version?

**Check #announcements for the latest playable release for your platform.** Compare its version with the one shown in your game and follow the matching installation or update instructions in **#mdpro4-download**.

A development version number is not a release announcement. Entries described as **synthetic updater fixtures** are for testing the updater, not for playing the game.

Platform releases can become available at different times, so use the package specifically announced for your device.

## Which languages are supported?

You can choose **UI Language** and **Card Language** separately in **Settings → General**.

The language set includes English, Spanish, French, German, Italian, Japanese, Korean, Portuguese, Thai, Simplified Chinese and Traditional Chinese.

Card translations and prerelease translations can have different coverage. If a card is missing or its text looks wrong, include the **card name/ID, selected language, game version and a screenshot** in your report.

## Why are some Master Duel features different or missing?

**MDPro4 has its own development and release process.** A feature needs working game logic, interface controls, assets and platform support before it can be offered reliably.

Sharing Master Duel's visual style does not mean every mode, event, animation or online service is available. Features may also depend on the selected duel engine.

For a request, describe what you want to do and include an example. For a broken existing feature, include your version, platform, mode and steps to reproduce it.

## Can I play on iPhone or iPad?

**There is no announced iOS release or release date in this FAQ.** Follow the project's release announcements for any change.

An Android APK cannot be installed as an iPhone app. Please use only a package explicitly released for your device.

## Do I need an internet connection?

**You need internet access to download the game, get updates and use online services.** The current base installers contain their resources for offline installation once the complete set has been downloaded.

Local play uses the content included in your installed release. Online duels, account services and downloading optional or newer packs require a connection.

An unfinished base installation must still be completed before ordinary play and patching can proceed.

## How do updates work?

**MDPro4 includes an in-game update system for published, supported update routes.** Finish the complete base installation first, then follow the update prompts.

You can usually skip intermediate releases when a cumulative patch is published for your installed version. On Android, an update that changes the application may also require a matching APK.

If no route is offered for your version, follow the release announcement. Patches replace changed files; they are not a full repair scan for every missing or damaged file.

Keep enough free space for downloads, extraction and temporary backups, and allow installation or recovery to finish.

## Where should I download MDPro4?

**Use #mdpro4-download and the matching post in #announcements.** Choose the package released for your platform and follow its installation instructions.

Download the complete installer set from the same release. Windows, Android, Linux and macOS use different packages; keep the original part filenames.

The download channel also contains the community installation guide. Follow the instructions for your exact release if an older guide shows different steps.

A GitHub **Source code** ZIP is not a ready-to-play installation. Synthetic updater fixtures are not the game either.

## Installation failed. What should I check?

**Keep the exact error message—it tells us where installation stopped.**

1. Check that every required part is present and belongs to the same platform, version and installer set.
2. Keep the original filenames. On desktop, place all parts beside the installer.
3. Check free space for both the downloaded files and the extracted game.
4. If a part fails verification, download that part again from an announced mirror.

On Android, install and open each numbered APK in order; wait for its completion message before the next one.

Still failing? Report your device/OS, release version, filename or part number, download source and exact error. Preserve any recovery or backup folder mentioned by the game.

## A mirror says its download quota was reached. What now?

**Try another mirror listed in the same release announcement, or try the affected host again later.**

A host's quota message does not mean your installed game is broken. Keep any parts that finished correctly and get the missing parts from another announced mirror of the **exact same installer set**.

If every listed source fails, report the release, filename, mirror and exact message so the download links can be checked.

## Why does the installer ask for “Disk 2”?

**It is looking for the next installer part. You do not need a physical disc.**

Download all numbered files listed for that release and keep them together beside the setup program. Keep their original names, including extensions. A browser-added suffix such as `(1)` can prevent the installer from finding a part.

If it still asks, check that the file finished downloading and belongs to the same installer set. Use the release's file list or checksums when available. Do not mix files from an older or rebuilt set, even if the displayed game version matches.

## Can I download installer parts from different mirrors?

**Yes, if the mirrors provide identical files from the exact same installer set.**

For example, you can get Parts 1–3 from one announced mirror and Part 4 from another. Keep the original filenames and verify checksums when supplied.

Match the platform, release and set—not just the version number. A repackaged installer can have different split boundaries while keeping the same game version. Never mix old and refreshed parts.

This helps you obtain the complete set. It does not combine several hosts into one faster download.

## Can I go back to an older version?

**Downgrading an installed game is not supported by the updater.** Do not apply an older patch or copy an old executable over a newer installation: the player, data and assets need to match.

If you need an older version for a specific reason, ask in **#troubleshoot** with your current version and platform. An older complete release, if still available, would need separate release-specific instructions.

Back up or export your decks, replays and custom content before changing installations. Newer saved data may not work in an older version, and uninstalling an Android app can remove its data.

## Can I delete the installer files afterward?

**After the complete installation finishes and the game opens successfully, you can remove the downloaded setup archives or APK copies to save space.** Keeping a backup set is useful if you want to reinstall without downloading everything again.

Delete only the installer files you downloaded. Keep the installed game, its resource folders, decks and replays. On Android, finish every required APK part before removing your downloaded copies.

Do not manually delete update recovery or backup folders while installation is running or an error still needs investigation.

## How do the numbered Android APK parts work?

**Each APK installs another part of the same offline resource set.**

1. Download the complete set for the announced Android release.
2. Install **Part 1**, open the game, and wait until that part finishes.
3. When the game says the part installed successfully, close it and install the next APK as an update to the same app.
4. Open the game after every part and continue until the full set is complete.

Keep enough free space for downloaded APKs and extracted resources. Do not uninstall the app between parts: the completed resources must stay in place. Installing all APKs without opening them in between does not extract each part.

If it stops, report the part number, completed count, device and exact message.

## I missed several updates. Must I install each one?

**Usually no—use the update offered for your installed version.** When a cumulative patch is published, it contains the changes needed to go directly from your version to the target release.

Windows can also process a supported chain of incremental patches in one update operation. Android, Linux and macOS need a published direct cumulative route.

Do not download every alternative patch or manually combine archives. If your version has no supported route, follow the release announcement's installation instructions.

## Can I install MDPro4 over MDPro3?

**Install MDPro4 as a fresh installation and keep a backup of your MDPro3 files.** The Workshop distribution treats MDPro4 as a new baseline, including a different Android app identity.

Export or copy the decks, replays and custom content you want to retain, then import supported files into MDPro4. Check them in the new game before removing the old installation.

Do not merge the entire MDPro3 game folder into MDPro4: old player files, bundles and configuration can conflict with the new release. Compatibility of every old replay or custom pack is not guaranteed.

## Are updater test releases playable game updates?

**No. Releases described as synthetic updater fixtures exist to test the update system.** They are not complete game releases or ordinary patches for your main installation.

Use only the playable release and update channel announced for players. Test fixtures belong in disposable test installations following the maintainer's instructions.

Pre-Release **card packs** are a separate feature: they add newer card content and should not be confused with updater test builds.

## How many cards are available?

The total changes with game data updates, Pre-Release packs, alternate artwork, and installed custom packs. Standard and Rush Duel also have different card pools.

For a specific card, search the Deck Editor with the relevant pool selected and restrictive filters cleared. Include your **game version, language, and card ID/name** when asking about something missing.

We avoid a fixed FAQ total because it would quickly become outdated.

## Are cards from a particular set included?

Check the card in the **Deck Editor** first. Update the relevant Standard or Rush Pre-Release pack if it is a newer card, then clear search filters that could hide it.

A card appearing in the editor confirms that its data is installed. It does not prove every interaction has been tested or that every online server supports it.

If you need help, give us the **set name, exact card name or ID, game version, language, and mode/server**.

## What are Pre-Release cards?

Pre-Release packs add newer cards and their scripts before they are included in the regular card data. Their translations and effects may change as the cards are reviewed.

**Standard and Rush Duel use separate packs.** Update the pack you need from **Settings → Expansions**, outside an active duel.

Having a card installed does not automatically make it legal or supported on every online server.

The project is now called [Pre-Release Translations](https://github.com/ElderLich/Pre-Release-Translations). The old **TransSuperpre** download location is retired.

These packs extend the **ocgcore** card pool; they do not add effects to the separate Master Duel native engine.

## A card is already released in the TCG/OCG. Why is it missing?

The physical release date and the simulator update schedule are separate. A card still needs to reach the game's data and scripts; translated packs can also need review before publication.

First update the relevant pack under **Settings → Expansions** and check your Deck Editor filters.

If it is still missing, tell us the **exact card name or ID**, your **language**, and your **game version**. The release of a physical set does not guarantee same-day availability in every language.

## I cannot find a new or Pre-Release card. What should I check?

1. Check whether it belongs to **Standard** or **Rush Duel**.
2. Outside a duel, open **Settings → Expansions** and update that Pre-Release pack.
3. Clear restrictive Deck Editor filters and check the relevant card pool.
4. Search by **card ID** if available; translated names can differ.

The pack follows your selected interface language. After changing languages, update the relevant pack again.

If it remains missing, report the card name/ID, language, game version, and any update error. Different languages may receive reviewed cards at different times; an update check cannot download unpublished content.

## Why is a new alternate artwork missing?

**Alternate artwork is added after its official OCG/TCG release, as part of a later game/data update.** An announcement or preview image does not mean the artwork is already included.

Check the current release notes and the card’s available artwork variants. If an artwork that should be present is missing, include the **card name, a reference image/link, game version and platform**.

This helps us distinguish artwork awaiting inclusion from an installed image that is failing to load.

## Why do the available cards change when I switch engines?

**The ocgcore and Master Duel native engines use different card data.** If your build offers engine selection, switching can change which cards and modes are available.

Pre-Release packs and ordinary custom Lua cards extend the **ocgcore** card pool. They do not automatically add those cards or effects to the native engine.

When reporting a missing card, effect problem or replay issue, include the **selected engine**, card name/ID, mode and game version. Attach the replay saved by that mode; keep its original file extension.

## How do I play online or invite a friend?

Open **Online** and choose the service or room you want to use. Both players need a compatible game version and the same server/room details.

**Inviting a friend**
Use **Copy link** for the selected server/room, or **Connection details → Copy join link** inside a room. Your friend can open the invitation or paste it into Online’s room-code field and select **Connect**.

**Playing over LAN**
One player creates the local room; the others connect using the host’s reachable IP address and the port shown in its connection details.

A LAN invitation does not create a network connection by itself. Room links may contain the password, so share them with the intended players.

## What IP address and port should my friend use?

The **host** is the player who created the local room. Other players need that host’s reachable IP address and the **actual room port**.

• On the same local network, use the host’s local network address.
• Through a shared VPN, use the host’s address on that VPN.
• **127.0.0.1 / localhost points to your own device**—do not send it to a friend as the host address.

Copy the port from the room’s connection details. Hosting normally searches from **7911**, but another available port may be used.

Across different networks, simply sharing a local IP address is not enough; the devices must have a reachable network route.

## Why does a server reject a card or my deck?

**The server decides which cards and decks it accepts.** A card appearing in your editor does not guarantee that it is available or legal on that server.

Possible reasons include the room’s card pool, banlist, deck-size rules, unsupported prerelease/custom cards, or different client/server data versions.

Read the exact rejection message and check the room settings. If it still seems wrong, include the **server, room rules, game version, card name/ID and complete error message**.

## Can players on different platforms duel together?

Use **compatible releases on the same supported server or room**. Both players must use compatible game data and any required custom content.

The operating system alone does not determine whether the connection will work: server compatibility, version differences and network reachability also matter.

If a mixed-platform connection fails, report **both platforms, both game versions, the server/room type and the exact error**. For LAN, check the host’s IP address and room port as well.

## Can I use the Master Duel banlist?

Where the mode offers banlist selection, choose an installed list marked **MD** and check its date.

For online duels, the **server or host’s selected rules** decide which cards are legal. Selecting an MD list in the Deck Editor helps you build for it, but does not change an existing server’s rules.

If the list you need is missing, check the latest release/data information before reporting its name and date.

## Why is the online room list empty?

A room list is not a count of every MDPro4 player. You may be viewing a particular service, room type or filter, and other players may be using a different service or private room.

Check the selected server and any filters. When joining a friend, ask for their **exact server and room invitation/code** instead of waiting for the room to appear.

If the list fails to load or shows an error, include the **service, time, game version and exact message** in your report.

## Why is my online timer wrong or negative?

**The server controls timeouts and match results.** The displayed clock is an estimate of the time information sent by that server; different services can also have separate inactivity rules.

A negative or clearly incorrect display should be reported. Include your **game version, server, screenshot/video, when it started and a replay if available**.

Do not assume that a frozen clock means the server has stopped counting time.

## I cannot join a LAN room. What should I check?

Check these in order:

1. The host has created the room and is still in it.
2. Everyone is using compatible game versions.
3. The guest entered the host’s reachable IP address and the room’s exact port.
4. Both devices are on the same reachable local network or shared VPN.
5. The host’s firewall permits MDPro4 on the intended network.

A guest should not use **127.0.0.1** to reach someone else’s device. Guest Wi-Fi or network isolation can also prevent devices from reaching each other.

If it still fails, include the **platforms, versions, network type, exact error and whether the room appears at all**. Keep private room passwords out of public screenshots.

## I can’t register a MyCard account. What should I do?

**Report the exact registration message and the step where it appears.** Account registration is handled by the account service, so reinstalling the game will not necessarily change it.

Check the registration form's requirements and any current service announcement. If the form fails inside the client, try the registration page linked by the service in your browser.

For help, include whether you used the client or browser, the time of the attempt and a screenshot with private details hidden. Never include your password or verification code in a public report.

## Can I put more than 15 cards in the Extra Deck?

**A normal Extra Deck is limited to 15 cards.**

The editor may hold a larger list for custom use, but that does not make it legal in a normal duel. Automatic additions start going to the Side Deck once the Extra Deck reaches 15.

The selected mode and the room/server decide whether a deck is accepted. For ordinary duels, keep the Extra Deck within the allowed limit.

## Why is the Solo bot list empty?

The Solo bot list is included with the game data.

• Clear any active search or filter.
• Check the selected UI language.
• Make sure installation finished and all required game-data parts were installed.

If the list is still empty, report your **game version, platform and UI language**, with a screenshot of the Solo screen and any loading error.

Use the data files supplied for your release; mixing bot catalogs or decks from unrelated versions can create missing entries or broken references.

## Why can’t the bot play my deck’s combos?

**WindBot uses programmed strategies for particular decks.** Giving a bot a different deck does not teach it that deck’s combos.

Start with the bot’s supplied deck. Custom-deck performance depends on its existing strategy and how well that strategy fits the cards you give it; unusual builds may produce weak or incorrect decisions.

To report a bot decision, include the **bot name, deck, game version, replay and the turn/action** where the problem occurs. Explain the play you expected it to make.

## Why is the bot using Maxx “C” or a forbidden card?

**The bundled local WindBot deck does not automatically rebuild itself around the banlist you selected in the Deck Editor.** Local Solo can therefore include cards that are forbidden in your preferred competitive format.

Check the bot’s deck, the duel mode and its deck-check settings. Online servers apply their own room rules. A card being forbidden in another format is different from an effect resolving incorrectly.

If you suspect an illegal effect or extra draw, attach the **replay, bot name, card name and turn** so the full game state can be checked.

## How do I test a one-card starting hand?

Open your deck, select **Test Hand**, set **Starting Hand** to **1**, then press **Start**.

The setup also lets you change Life Points, the rule, shuffling and whether a replay is saved when leaving. Turn **No Shuffle** off when you want a shuffled draw.

If your version does not show these options, check the current release information. If Test Hand stalls or Retry fails, report your **version, selected rule, settings and deck**.

## Why am I hearing different duel music?

Check **Settings → Audio → Music**:

• Music can follow **your field** or **your opponent’s field**.
• **Custom Duel Music** can replace the usual field soundtrack.
• Some fields share music, and some change tracks as the duel progresses.

If music is missing, also check the BGM volume. If the wrong track still plays, report the **field, music settings, game version and when it happens**; a short recording helps.

## The game is stuck on the loading screen. What should I check?

**Start with the last message shown on screen.** A loading problem can come from an incomplete installation, missing data, unavailable storage or a specific startup error.

1. Confirm that installation and all required resource parts completed.
2. Check free space and that the installed game folder is accessible.
3. On Android, a message telling you to install the next APK means the base set is still incomplete. Follow that instruction.
4. If an error is displayed, copy it or take a screenshot before changing files.

Report your version, device/OS, last loading message and whether this followed an installation or update. Attach the game log if available.

Running as administrator is not a general fix; investigate a permissions error only when the message points to one.

## How can I access game files on Android 11 or later?

**Android restricts access to app data folders, so a file manager may be unable to open `Android/data`.**

Use the game's **Import** and **Export** controls for supported files such as decks, replays and expansion packs. Place files you want to import in an ordinary user-accessible folder, then select them through the file picker.

Export anything you want to keep before uninstalling or clearing app data. If an import fails, report the Android version, file type and exact message.

[Android storage restrictions](https://developer.android.com/about/versions/11/privacy/storage)

## I click Join or Connect and nothing happens. What now?

Check that you have a **player name**, the correct server address and port, and the right room code/password. Read any message shown near the action or in the game’s notifications.

If you are opening a room invitation, finish or leave an active room, duel or deck-editing session first; the invitation may wait until that session ends.

For account-based services, also check that you are signed in. If the action still fails, report the **service, exact button/screen, version, platform and any error**, ideally with a short video. Remove passwords or private account information from attachments.

## My controller stops working in a duel. Is it supported?

In builds with the updated controller system, controller navigation includes **duel selections**, with button remapping under **Settings → Controls**. Follow the on-screen hints, which reflect the active bindings.

If an action cannot be reached, report the **controller model, USB/Bluetooth connection, platform, game version and exact screen or duel prompt**. Mention whether the same action works with mouse/touch and whether you changed the bindings.

For a duel issue, attach the replay and a short video showing the input problem when possible.

## I see a black screen or missing card artwork. What should I check?

**First check whether the whole screen is affected or only certain cards.**

If the issue appears when animated artwork plays, try turning **Animated Card Art** off in **Settings → Appearance**, then reopen the same screen. Older versions may place this option under General. This is a diagnostic workaround for animation-related problems.

If static art is also missing, verify that the complete resource installation finished. A missing artwork file or platform asset problem needs a different fix.

If it persists, report your device/GPU, OS, game version, affected card names/IDs, screenshot and whether disabling animation changed anything.

## Why do my cards appear as “UNKNOWN”?

**“UNKNOWN” does not identify one specific cause.** The client may be missing the card's data, using the wrong card pool, or failing to load its database.

If **many or all cards** are affected, check that the full installation completed and note any database/startup error. If **only a few cards** are affected, include their IDs and check whether they belong to a custom or Pre-Release pack.

On Windows, a missing-runtime or DLL error may require the matching [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). Follow the error and release instructions; installing every runtime is not a universal solution.

Report your version, OS, language, selected mode/engine, screenshot and relevant log. A deliberately hidden opponent card is different from a known card unexpectedly becoming UNKNOWN.

## Can I play custom cards online with a friend?

For **ocgcore custom cards**, use a **private/LAN host that supports the custom pack**. Everyone needs matching card data, and the duel host needs the matching scripts.

Installing a custom card on your device does not upload it to a public server. A public server's **Custom cards** option refers to the card pool that server supports.

Agree on the same pack version and compatible game version before testing. If the room rejects the deck, check its permitted card pool and rules as well as whether the host has the pack.

## Where should I report a problem or contact the team?

For **MDPro4 crashes, installation/update failures, interface issues, artwork, controller behavior or translations**, use this server’s bug-report area and its template. Search existing reports first and keep one issue per report.

For suspected **YGOPro/ocgcore card-effect or script problems**, use [MyCard Forum](https://ygobbs2.com/c/%E9%97%AE%E9%A2%98%E5%8F%8D%E9%A6%88/10). Include the **.yrp3d replay**, card names and the turn/action. If it happened in Local AI, compare with Server AI when possible.

If the issue occurs specifically in an MDPro4 native-engine mode, report it here with that engine named and its saved replay if available. Native replay files use **.mdreplay**; do not rename them to .yrp3d. Do not send a client-only visual issue as a card-script bug.

Include your exact version and clear reproduction steps; a public ticket makes the investigation easier to follow.

## How do I create a WindBot deck AI?

WindBot deck logic is written in **C#**. A `.ydk` file supplies the cards; a **deck executor** teaches the bot when and how to use them.

Start with an existing executor close to your deck in [windbot-elder](https://github.com/ElderLich/windbot-elder), then implement and test the decisions your cards need.

Changing the deck list alone does not teach new combos. When asking for help, include the executor code, deck list, a reproducible situation, and the move you expected.

## How do I make custom animations or visual content?

First decide what you want to make: **card art, a summon cut-in, a wallpaper, a character, or a full animation**. They use different formats and workflows.

For a first project, begin with supported DIY images or a character pack. Full animations need compatible assets, effects, and support for the target platform; exporting an animation file alone is not enough to make it work in-game.

When asking for help, include your **goal, platform, game version, and a short preview**. Use the instructions supplied with your installed version, since newer customization features may not be in older releases.

## How do I make custom cards?

For the **ocgcore engine**, a working custom card has three parts:

• **Database:** ID, name, text, type, and stats.
• **Lua script:** what the effects actually do.
• **Artwork:** how the card looks.

Use [DataEditorX](https://github.com/ElderLich/DataEditorX) to edit the database and scripts. Follow [MDPro4 Sacred Book](https://elderlich.github.io/MDPro4_Sacred_Book/) for the learning path, functions, and examples.

Start with one simple effect, keep its database ID and script filename consistent, and test locally. Writing effect text in the database does not implement the effect.

Some DataEditorX menus still use the **MDPro3** name.

## How can I help improve translations?

**Interface text and card text use different workflows.**

For menus, buttons and messages, report the **screen, language, current wording and suggested correction**, preferably with a screenshot.

For card names, effects or prompts, include the **card ID/name and language**. To help with Pre-Release cards, start with the [Pre-Release translator guide](https://github.com/ElderLich/Pre-Release-Translations/blob/main/docs/TRANSLATOR_WORKFLOW.md), which explains the language workspace and DataEditorX workflow.

Translate text while keeping card IDs and gameplay values unchanged. You can report a small correction without setting up the whole toolchain.

## Where can I learn Lua and card scripting functions?

Start with [MDPro4 Sacred Book](https://elderlich.github.io/MDPro4_Sacred_Book/).

• **Learn:** Lua essentials, your first card, activation flow, and debugging.
• **API:** functions and constants when you need an exact call.
• **Examples:** real card scripts to study.
• **Script Explorer:** find cards and existing patterns by text, ID, or function use.

Rush Duel also has its own lessons and helper reference.

Keep [DataEditorX](https://github.com/ElderLich/DataEditorX) open beside the guide and build one small, testable effect at a time.
